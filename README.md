# InspectTheFootRoom

检查地面上的东西，如果发现门卡，钥匙或者皇冠，就输出文字。
加入了地图的标识，那就可以通过小地图找到对应的物品了。

第一次搞这些东西，都是根据各个大神的Mod摸石头过河的，请多包涵。

Github: https://github.com/leocxy/InspectTheFootRoom
